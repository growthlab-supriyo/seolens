# Simple Scope (online demo)

A free, open-source SEO crawler and site audit tool. This demo crawls up to **500 URLs** per run without JavaScript rendering.

For crawls of up to **10,000 URLs**, install it free on your own computer:

```bash
pipx install simple-scope
simple-scope
```

Source code: https://github.com/growthlab-supriyo/simple-scope
